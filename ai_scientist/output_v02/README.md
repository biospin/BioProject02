## 특징

- **오프라인 렌더** — `mermaid.min.js`를 로컬에서 먼저 읽고, 없으면 CDN으로 폴백한다. 두 파일을 함께 두면 네트워크 없이 동작한다.
- **테마 대응** — 우상단 `◐ 테마` 버튼으로 라이트/다크 전환(다이어그램도 함께 리렌더). 시스템 테마 자동 감지 + 선택 기억.
- **사이드바 + scrollspy**, 모바일 폭에서 접힘, 표·다이어그램 가로 스크롤.

## 읽는 순서

설계를 처음 보면 **개요 → 01 → 02 → …** 순서로. **무엇이 미완성인지**가 궁금하면 사이드바의 **⚠️ 미해결 갭 5건**으로 바로.

## 주의

- **갭 5건은 "변경 이력"에 없다.** 관찰된 갭이지 채택된 설계 변경이 아니기 때문이다. 변경 이력에 넣으면 "설계가 이렇게 바뀌었다"로 잘못 읽힌다.
- GAP 3·4·5를 실제로 고치려면 `.claude/agents/*` · `schemas/*` · `auto_review_config.json`을 건드려야 하고, 그것은 **Critic이 자기 검수 기준을 스스로 정하는 일**이라 `CLAUDE.md`의 `❌ anti-self-reference`에 걸린다 → **Leader 승인 사안.**
- `mermaid.min.js`(3.2 MB)는 vendored 파일이다. 리포에 커밋할지는 팀 판단 — **커밋하지 않아도 CDN 폴백으로 동작**한다.
