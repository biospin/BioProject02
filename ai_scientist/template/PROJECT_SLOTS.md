# PROJECT_SLOTS — 이 프로젝트의 값을 채우는 단 한 장

템플릿 전체에서 `{{SLOT}}` 로 표시된 자리를 여기서 채운다. **이 표가 채워지기 전에는 하네스를 켜지 않는다.**

> **원칙:** 값을 못 채우는 슬롯은 "나중에 정하면 되는 것"이 아니라 **아직 설계가 안 된 것**이다.
> 특히 ⚠️ 표시 슬롯은 BIOP02가 비워둔 채 운영하다 실제 비용을 치른 자리다([APPENDIX](APPENDIX_CASE_BIOP02.md)).

---

## A. 프로젝트 정체성

| 슬롯 | 설명 | 값 |
|---|---|---|
| `{{PROJECT_NAME}}` | 프로젝트 이름 | |
| `{{PROJECT_GOAL}}` | 한 문장 목표 (입력 → 출력) | |
| `{{PROJECT_NOT}}` | **이 프로젝트가 아닌 것** — 오해받기 쉬운 인접 문제 | |
| `{{SCOPE_BOUNDARY}}` | 의도된 경계와 그 이유 (확장 금지선) | |
| `{{OUTPUT_KIND}}` | 산출물 성격 (논문 전용 / 제품 / 내부 보고) | |

> `{{PROJECT_NOT}}`을 못 쓰면 하드룰(금지 프레이밍)도 못 쓴다 — 둘은 같은 문장의 앞뒤다.

## B. 도메인 분석 레이어 (레이어 A)

| 슬롯 | 설명 | 값 |
|---|---|---|
| `{{DOMAIN_AGENT}}` | 도메인 분석 슬롯 에이전트 이름 | |
| `{{PIPELINE_STAGES}}` | 역할 체인 (예: 데이터 → 전처리 → 모델링 → 근거연결 → 검수) | |
| `{{ROLE_WORKSPACES}}` | 역할별 디렉토리 구조 | |
| `{{EXPERIMENT_DIR}}` | 실험 디렉토리 규약 | |
| `{{REQUIRED_ARTIFACTS}}` | 실험마다 강제할 산출물 목록 | |
| `{{METRIC_FIELDS}}` | 결과 파일 필수 필드 (+ 커밋 해시 필수) | |

> 아티팩트 강제는 **"실험을 실제로 수행했다"의 재현 가능한 증거**다. 목록이 짧아도 좋지만 **비어 있으면 안 된다.**

## C. 주장 규율 (claim discipline)

| 슬롯 | 설명 | 값 |
|---|---|---|
| `{{CLAIM_LEVEL}}` | 허용되는 주장 수준의 기본값 | |
| `{{FORBIDDEN_PHRASES}}` | **하드룰 — 즉시 차단할 과잉주장 표현** | |
| `{{FORBIDDEN_SAFE_MARKERS}}` | 위 표현이 "금지 설명" 맥락일 때 면제할 마커 | |
| `{{META_FILES}}` | 금지어를 설명하는 문서(자기 검사 면제 대상) | |

> ⚠️ 하드룰은 **도메인마다 다르다.** 남의 금지어 목록을 그대로 쓰면 자기 분야의 과잉주장은 못 잡고 엉뚱한 문장만 막는다.

## D. 검수 · 게이트

| 슬롯 | 설명 | 값 |
|---|---|---|
| `{{CHECKLIST}}` | 검수 체크리스트 항목 (n-point) | |
| `{{TIER_C_PATHS}}` | 사람이 반드시 판정할 경로 패턴 (헤드라인·공개물) | |
| `{{TIER_A_PATHS}}` | 가벼운 경로 (문서·설정) | |
| `{{DEFAULT_TIER}}` | 기본 티어 | |
| `{{INDEPENDENT_PASSES}}` | AI 적대 리뷰 독립 패스 수 | |
| `{{MODEL_DIVERSITY}}` | ⚠️ **독립 패스의 모델 계열 요구** (같은 모델 반복은 자기선호 편향을 상쇄 못 함) | |
| `{{VERIFY_GATE_1_CMD}}` | ⚠️ **게이트 ① 실행 명령** — 헤드라인 숫자 결정론 재계산 | |
| `{{VERIFY_GATE_2_CMD}}` | ⚠️ **게이트 ② 실행 명령** — 공개 직전 본문↔결과 재대조 | |
| `{{CI_VALIDATORS}}` | CI에서 blocking으로 돌릴 결정론 검증기 | |
| `{{ADJUDICATORS}}` | Tier C 최종 확인 담당(사람), 산출물 유형별 | |

> ⚠️ `{{VERIFY_GATE_1_CMD}}`가 비면 **하네스의 중심이 빈 채로 도는 것**이다. BIOP02는 이 자리를 비워둔 채 운영해, 게이트를 사람이 수동 대조로 메웠다.
> **문서 규칙 검사(금지어·필드 존재 확인)를 수치 재계산으로 착각하지 않는다** — 둘은 다른 도구다.

## E. 사람 · 협업

| 슬롯 | 설명 | 값 |
|---|---|---|
| `{{TEAM_TABLE}}` | 1인 1역할 표 (이름 · 역할 · 워크스페이스) | |
| `{{LEADER}}` | 리더 (스코프·승인) | |
| `{{CRITIC_LEAD}}` | 검수 총괄 (판정 owns) | |
| `{{CROSS_REVIEW_MAP}}` | 작성자 → 리뷰어 매핑 (**owner ≠ reviewer**) | |
| `{{SUBCHECK_RULE}}` | 도메인 sub-check 선정규칙 (후보 목록이 아니라 **규칙**) | |
| `{{HANDOFF_FILES}}` | 상태 인수인계 파일 | |

> ⚠️ 매핑은 **"기본 후보"가 아니라 "owner가 아닌 사람"** 이 이긴다. 고정 배정으로 적어두면 후보가 owner인 순간 규율을 어기게 된다.

## F. 인프라 · 도구

| 슬롯 | 설명 | 값 |
|---|---|---|
| `{{TRACKER}}` / `{{TRACKER_KEY}}` | 이슈 트래커 · 프로젝트 키 | |
| `{{TRACKER_HOST}}` | 트래커·위키 호스트명 (API 호출용) | |
| `{{WIKI}}` | 문서 공간 | |
| `{{WIKI_SPACE_ID}}` / `{{WIKI_PARENT_ID}}` | 위키 스페이스 id · 상위 페이지 id | |
| `{{CHANNELS}}` | 알림 채널 (공지 / 개발 / 결과공유 / 장애) | |
| `{{NOTIFY_BOT}}` | 트래커 → 채널 알림 봇 | |
| `{{SOURCE_OF_TRUTH}}` | ⚠️ **정보별 정본 표** — 어느 시스템이 무엇의 정본인가 ([INTEGRATIONS §0](INTEGRATIONS.md)) | |
| `{{SHARED_VOLUME}}` | **계정 간 공유되는 경로** (개인 홈은 공유 안 됨) | |
| `{{COMPUTE}}` | 연산 자원 + 예약 규칙 | |
| `{{ENV}}` | 실행 환경 (인터프리터·경로) | |
| `{{ACK_REQUIRED}}` | 논문 Acknowledgments에 명시할 자원 제공처 | |

## G. 공개 게이트 (사람 승인, 자동화 금지)

| 슬롯 | 설명 | 값 |
|---|---|---|
| `{{AUTHORS}}` | 저자·소속·저자순서 | |
| `{{CORRESPONDING}}` | 교신저자 | |
| `{{TARGET_VENUE}}` | 목표 저널·학회 | |
| `{{IP_POLICY}}` | 지식재산·라이선스 | |

> 이 절이 비어 있으면 **공개만** 막힌다(작업·커밋은 진행 가능). 초기에 못 정하는 게 정상이니 **비워둔 채 시작하되 공개 전에 반드시 채운다.**

## 채움 완료 체크

- [ ] A~F 슬롯에 `{{ }}`가 남아 있지 않다
- [ ] ⚠️ 슬롯 5개(`MODEL_DIVERSITY`·`VERIFY_GATE_1_CMD`·`VERIFY_GATE_2_CMD`·`FORBIDDEN_PHRASES`·`SUBCHECK_RULE`)를 **미루지 않고** 정했다
- [ ] 검수 기준(C·D절)을 **검수 총괄 본인이 아닌 사람**이 승인했다 — 자기 기준을 자기가 정하지 않는다
- [ ] 원본 하네스 저작자 표시(CC BY 4.0)를 유지했다
