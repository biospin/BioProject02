## Phase 0 — 규율 먼저 (코드 0줄)

> 가장 흔한 실패는 **에이전트부터 만드는 것**이다. 판정 기준이 없는 상태에서 검수 에이전트를 붙이면 그 에이전트가 자기 기준을 만들어 버린다.

- [ ] `{{PROJECT_GOAL}}` 과 **`{{PROJECT_NOT}}`** 을 한 문장씩 쓴다
- [ ] `{{FORBIDDEN_PHRASES}}` — 이 도메인에서 **하면 안 되는 주장**을 표현 수준으로 적는다
- [ ] `{{CLAIM_LEVEL}}` 기본값을 정한다
- [ ] `{{REQUIRED_ARTIFACTS}}` · `{{METRIC_FIELDS}}` — 실험이 남길 증거를 정한다
- [ ] **검수 기준을 검수 총괄이 아닌 사람이 승인**한다 (anti-self-reference)

**산출:** 프로젝트 루트에 규율 문서 1개(에이전트 지침서 겸용).

## Phase 2 — 레이어 B (논문 생산 하네스)

- [ ] 재사용 에이전트 정의를 복사한다 (문헌·기획 3 / 집필 2 / 심사 2 / 코디 1 / 디자인 1)
- [ ] **`{{DOMAIN_AGENT}}` 하나만 새로 쓴다** — 도메인 지식은 여기에만 넣는다
- [ ] **에이전트별 `tools:` 를 명시 선언한다** — 미선언은 전체 도구 상속이다
  - 검수 계열: 쓰기 권한 제거 (읽기·검색·실행만)
  - 게이트 이후 수정 계열: 새 파일 생성 없이 **편집만** 하도록 분리 고려
- [ ] 라우팅표 작성 (자연어 → 에이전트)
- [ ] 산출물 계약표 작성 (단계 → 산출 파일 → 다음이 읽음)
- [ ] 오케스트레이터 입구 1개 (실행) + 계획 전용 1개 (계획만) 분리

**게이트:** "이 요청은 누가 받나"를 팀원이 문서만 보고 답할 수 있으면 통과.

## Phase 3 — 게이트 배치 ⚠️ 여기서 미루지 않는다

- [ ] **`{{VERIFY_GATE_1_CMD}}` 를 실제로 만든다** — 헤드라인 숫자를 결과 파일에서 **결정론적으로 재계산**해 대조하는 명령
- [ ] `{{VERIFY_GATE_2_CMD}}` — 공개 직전 본문 ↔ 결과 재대조 + 동봉물 확인
- [ ] 순서를 고정한다: **내부 검수 → 🔒 게이트 ① → (선택) 외부 리뷰 → 🔒 게이트 ② → 공개**
- [ ] 🔒 공개 게이트 조건 명시 (G절 슬롯)

> **왜 여기서 미루면 안 되나:** 게이트 ①이 비면 "검증했다"는 말이 사람의 기억에 의존하게 되고, 그 상태로 몇 달이 지나면 **무엇을 검증했는지 재구성할 수 없다.**
> 그리고 **문서 규칙 검사(금지어·필드 존재)를 수치 재계산으로 착각하지 않는다.**

## Phase 4 — 검수 3층

- [ ] **① CI 결정론 검증기** — `{{CI_VALIDATORS}}`를 PR/push에 blocking으로 건다
  - 결정론·오프라인 검증만. **LLM 판단은 CI에 넣지 않는다**
  - 최소 3종 권장: 검수기 회귀 테스트 · 인용 검증기 회귀 테스트 · **숫자 드리프트(정본 ↔ 문서 표)**

  - 결정 항목은 **전부 config로** 빼고 코드는 도메인 무관하게 유지
  - **기본값 `enabled=false`(dry-run)** 으로 시작
  - `{{INDEPENDENT_PASSES}}` + ⚠️ `{{MODEL_DIVERSITY}}`
- [ ] **③ 사람 게이트** — 티어 규칙(`{{TIER_C_PATHS}}` / `{{TIER_A_PATHS}}` / `{{DEFAULT_TIER}}`)과 `{{ADJUDICATORS}}`

**설계 의도:** 사람이 하드 블로킹하는 건 **헤드라인·공개**뿐. 나머지는 AI 리뷰 통과 시 진행하되 **공유만** 사람 확인.

## 최소 구성 (인원 1~2명, 빠르게 시작)

전부 다 세울 여력이 없으면 **이 순서로 자른다.** 아래 4개는 빼지 않는다.

| 우선 | 항목 | 뺐을 때 생기는 일 |
|---|---|---|
| 1 | `{{FORBIDDEN_PHRASES}}` + `{{CLAIM_LEVEL}}` | 과잉주장이 원고까지 살아남는다 |
| 2 | `{{REQUIRED_ARTIFACTS}}` 강제 | "그때 그 숫자"를 재현할 수 없다 |
| 3 | **게이트 ①** 실행 명령 | 검증이 기억에 의존한다 |
| 4 | owner ≠ reviewer | 자기 결과를 자기가 통과시킨다 |

뒤로 미뤄도 되는 것: CI 3층(나중에 추가 가능), 외부 리뷰 에이전트(선택), 발표·디자인 벤치.

## 리뷰어가 1명뿐일 때

- AI 적대 **독립 패스 ≥3** + 리더 확인으로 진행하되, 라벨로 그 사실을 남긴다
- 단 **헤드라인은 타인 1인 확인 필수**
- ⚠️ 독립 패스는 **모델 계열을 달리한다** — 같은 모델 반복은 자기선호 편향을 상쇄하지 못한다
