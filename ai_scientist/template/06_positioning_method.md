# 06 — 포지셔닝 방법론 (결론이 아니라 절차)

> ⚠️ **이 문서에는 "정답"이 없다.** 다른 프로젝트의 포지셔닝 결론(무엇이 포화됐고 무엇이 novelty인가)은 **그 프로젝트의 것**이다.
> 베끼면 남의 분야 판단으로 자기 기여를 규정하게 된다. 여기 있는 것은 **그 결론에 도달하는 절차**뿐이다.

## 왜 이 단계가 하네스의 일부인가

다중 에이전트로 연구를 자동화하는 순간 **"우리 기여가 뭔가"** 가 흐려진다. 파이프라인이 돌아가는 것과 기여가 있는 것은 다른 문제다. 그래서 포지셔닝을 **기획 단계의 정식 산출물**로 둔다.

## 절차

### 1단계 — 영역을 나눠 병렬 조사한다

한 덩어리로 "선행연구 조사"를 시키지 않는다. **영역(축)별로 쪼개** 각각 조사하고 인덱스를 만든다. 축 예시:

- 우리가 쓰는 **기반 기술·백본**
- 우리가 푸는 **문제 자체** ← 스쿱 위험이 가장 높은 구역
- 우리가 붙이는 **응용·전이 레이어**
- **평가·엄밀성**(누수·기준선·통계)
- **시스템·에이전트** 계열 (이 하네스 자체의 선행연구)

**산출:** 영역별 문헌 목록 + 기계 판독 가능한 인덱스(제목·저자·연도·식별자·검증 여부).

### 2단계 — 스쿱 위험을 등급으로 매긴다

각 선행연구를 다음으로 분류한다:

| 등급 | 뜻 |
|---|---|
| **직접 스쿱 후보** | 같은 문제 + 같은 데이터 + 공개 코드 → **가장 위험한 직접 기준선** |
| 부분 스쿱 | 문제의 일부를 이미 해결 |
| 인접 | 방법은 겹치나 문제가 다름 |
| 배경 | 인용은 하되 경쟁하지 않음 |

> ⚠️ **"여러 논문이 확인했다"가 독립 확인이 아닐 수 있다.** 같은 공개 데이터셋·같은 코호트를 쓴 연구들은 **하나의 증거에 가깝다.** 출처의 독립성을 따로 확인한다.

### 3단계 — 정직하게 인정한다

직접 스쿱 후보가 있으면 **경쟁자가 아니라 기준선으로 인용**한다. 숨기면 심사에서 반드시 드러나고, 그때는 기여 전체의 신뢰가 흔들린다.

### 4단계 — 방어 가능한 white space를 찾는다

단일 논문이 다루지 않은 **조합**을 찾는다. 흔히 남아 있는 자리:

- 개별 부품은 있으나 **통합 시스템**이 없음
- 성능은 있으나 **평가·검증 프로토콜**이 없음
- 결과는 있으나 **거버넌스·주장 규율**이 없음
- 단일 데이터셋 결과는 있으나 **교차 데이터셋 일관성**이 없음

### 5단계 — 기여문을 한 문장으로 쓴다

```
우리의 기여는 [새 method / 새 system / 새 evaluation / 새 governance] 이고,
그것을 [가장 싼 실험]으로 입증한다.
```

**"멀티에이전트를 썼다"는 기여가 아니다.** 그건 이미 붐비는 영역이다. 기여는 그 위에서 **무엇을 다르게 보장하는가**에 있다.

### 6단계 — 하네스 계열 선행연구를 별도로 읽는다

이 하네스 자체가 선행연구를 갖는다. 최소 세 갈래를 읽고 **자기 위치를 좌표로 표시**한다:

| 갈래 | 읽고 답할 질문 |
|---|---|
| **완전 자율 연구 파이프라인** | 우리는 자율성을 어디까지 허용하나? 왜 거기서 멈추나? |
| **다중 에이전트 협업·아이디어 생성** | 협업 구조 자체는 이미 선행됐다 — 우리 delta는 무엇인가? |
| **LLM-as-judge와 그 편향** | 자기선호 편향을 우리는 어떻게 막나? (→ [04](04_automated_review_and_governance.md) 모델 다양성) |

> 세 번째 갈래는 **읽고 끝내면 안 된다.** 편향을 인용해 놓고 대응책이 *"같은 모델 반복"* 이면 인용이 근거를 못 받친다.
> **인용한 문헌이 자기 설계를 반박하고 있지 않은지** 점검한다.

## 인용 위생 (이 단계의 산출물에 바로 적용)

- 식별자(DOI 등)를 **검증**하고, 미검증은 `unverified`로 표시한다
- **검증 스크립트로 확인한다 — 눈으로 보지 않는다**
- 조회 실패는 **통과가 아니라 에스컬레이션**이다
- 철회(retraction) 여부를 확인한다. 확인 절차가 없다면 **그 사실을 한계로 적는다**

## 산출물

| 파일 | 내용 |
|---|---|
| 문헌 인덱스 | 영역별 목록 + 기계 판독 인덱스 |
| 포지셔닝 노트 | 스쿱 등급 + white space + 기여문 한 문장 |
| 가장 싼 입증 실험 | 기여를 증명할 최소 실험 설계 |

## 자기 점검

- [ ] 직접 스쿱 후보를 **찾았고**, 숨기지 않고 기준선으로 인용했다
- [ ] 기여문이 "우리도 X를 했다"가 아니라 **"우리는 X를 보장한다"** 로 쓰였다
- [ ] 인용한 문헌 중 **우리 설계를 반박하는 것**이 있는지 확인했다
- [ ] 모든 식별자가 검증됐거나 `unverified`로 표시됐다
- [ ] 결론을 **다른 프로젝트에서 베끼지 않았다**
