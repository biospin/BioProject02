## 3. 분담 (BIOP02 co-first 반영)

- **BIOP01(80G)**: kkkim 메인 → kkkim 단독 부담 무방(소량).
- **BIOP02(300G)**: kkkim·이건규 co-first → **저장 비용·디스크·작업 분담 협의**. 이건규가 RunPod 이전을 주도 중이라 **B안이면 분담이 자연스럽게 합류**(별도 정산 최소화).

## 4. 권장 (초안)

1. **1순위 B(RunPod volume)** — 다음 시즌 GPU 재사용까지 한 번에 해결(이전=재활용). 이건규 RunPod 조율에 합류.
2. **안전마진으로 A 병행** — B 세팅이 지연되면 **유일본 최소 80G(다중FM 71G + CONCH 9G)만이라도 외장에 즉시** 복사(진짜 못 만드는 것부터). raw·재계산 가능분은 후순위.
3. **D는 피한다** — 교차암 재추출 5일 GPU는 비용·일정 모두 손해. 단 egress가 끝내 안 되면 유일본만 A, 나머지는 D 수용이 현실 타협.
